# 브레멘 음악대 · Bremen Town Musicians

Korean children's play «브레멘 음악대» as an interactive cartoon player: voices, subtitles (KO / RU / EN) and a rehearsal mode — pick a role, hear the model line, say it yourself, press Space.

Open: https://dmitriiree.github.io/bremen/

Voices: ElevenLabs (eleven_v4). The tale is the Brothers Grimm; Korean script is a school play adaptation.
